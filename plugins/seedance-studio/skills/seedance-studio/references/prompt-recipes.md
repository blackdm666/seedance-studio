# Paste-ready prompt recipes

Replace bracketed text and preserve real reference tags exactly.

## Simple standalone clip

`[主体]在[场景]中[主要动作]，最终[可见终点]。镜头从[起点景别]缓慢[单一运镜]至[终点景别]；[物理光源]形成[光影效果]。声音为[环境声/音效/对白/静音]。保持[人物/产品/道具]一致，无字幕、无无关BGM。`

## Image-to-video

`严格保持@图片1的人物脸、发型、服装、体型和背景构图不变；仅加入[动作]与[环境运动]。镜头[单一运镜及终点]，[物理光源变化]。动作结束于[终态]。声音为[声音设计]，无字幕、无无关元素。`

## 30-second timestamp story

`@图片1控制主角身份。[一句话故事与风格]。0–8秒：[开场状态、动作、镜头、声音、终点]。8–18秒：[触发、反应、转场、终点]。18–30秒：[高潮、结果、最后画面]。全程保持主角脸、服装、体型、道具与空间连续；[声音政策]；无字幕、无变形、无突兀跳切。`

## Ultra-long story

`全片[时长]，画幅[比例]。[参考角色/场景/声音映射]。[故事主题和最终结局]。0–[A]秒：[开场]；[A]–[B]秒：[升级]；[B]–[C]秒：[转折]；[C]–[D]秒：[高潮]；[D]–[结束]秒：[收束和最终画面]。全程保持[身份/服装/比例/核心道具/视觉母题]一致，场景切换有明确物理或叙事桥梁，[声音政策]，无字幕、无Logo、无闪烁和动作重置。`

## Seamless native extension

`参考@视频1的已生成内容，向后延长[时长]，完整保留原视频，新增提示词只作用于延长部分。从原视频结尾的[人物姿态/动作方向/镜头阶段/环境声]继续：[新动作及结果]。动作、视线、速度、镜头、光线、环境运动和声音连续；禁止生硬切镜，禁止物体凭空出现。`

## Precise edit

`在[时间范围]，将[标注工具/位置]内的[对象A]修改为[对象B及材质/行为]；[出现方式或持续方式]。保留人物身份、动作、机位、背景、光影、口型、音频和原始剪辑节奏不变。`

## Remove BGM but keep speech

`移除整段视频的背景音乐，仅保留人物原声、对白、环境声和必要音效；画面、字幕、口型、时长和剪辑节奏全部不变。`

## Green-screen replacement

`将@视频1的绿幕人物自然合成到@图片1的[目标场景]。清除绿色溢色，保留人物动作、脸、服装、口型和时间不变；匹配[方向]主光、环境反射、透视、地面接触阴影、景深和运动模糊，边缘干净稳定、无闪烁和贴片感。`

## Creative transfer

`@视频1只控制[动作节奏/情绪曲线/运镜/创意结构]，不迁移其中人物、服装、场景、声音、文字或Logo。@图片1控制新主角身份，@图片2控制新场景。[描述新故事动作与终点]。`

## Fine white-model render

`将@视频1的白模动画渲染成最终成片，严格保留运镜、角色站位、空间关系与动作时间。0–[X]秒：[材质、环境、光影]；[X]–[结束]秒：[变化与收束]。将白模角色映射为@图片1，将场景渲染为@图片2；不保留白模材质、轨迹线、坐标轴、相机锥体或视口界面。`

## Multi-panel storyboard

`@图片1是按[阅读顺序]排列的[N]格连续分镜，每格代表一个完整镜头。角色A参考@图片2，场景参考@图片3。镜头1（0–Xs）：[构图、景别、运镜、动作、终点]；镜头2（X–Ys）：[承接上个终点的动作与转场]；…… 全片保持人物、服装、比例、道具、光线方向与空间连续；无字幕、无Logo、无多余人物。`

## Seamless transition between two sources

`不修改@视频1与@视频2。让@视频1尾帧的[共享载体]沿[方向]运动并遮满/占满画面，在过渡中转化为@视频2开头的[匹配载体]；衔接点的位置、尺寸、速度、方向、光线和运动模糊连续。禁止黑屏、跳帧、硬切、闪烁、字幕和Logo。`
