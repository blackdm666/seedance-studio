# 可复刻工程包（功能三）

目标：把一条参考视频变成**任何人拿着就能重新生成的完整工程**，而不只是一段提示词。好视频 = 提示词 × 素材绑定 × 时间结构，三者缺一不可。

## 第一步：证据分析

完整执行 [reverse.md](reverse.md)：元数据 → 联系表 → 密集帧逐帧观察 → 音频与文字时间线。所有结论标注 `已确认 / 推断 / 未知`。

## 第二步：结构化分镜

在 pipeline.md 的 `shotlist.json` 结构上，为每段追加复刻专用字段：

```json
{ "id": "seg01", "seconds": 3, "beat": "钩子",
  "camera": "低机位快速推近", "action": "手撕开包装袋，内容物弹出",
  "product_role": "主体·特写", "onscreen_text": "『3秒开袋』白字描边，右上，0.5–2.5s",
  "audio_evidence": "撕裂声（已确认）+ 口播第一句", "confidence": "已确认" }
```

## 第三步：素材盘点（本功能的核心价值）

逐镜清点后输出两份清单：

**A. 必须由用户提供（AI 不能编造的）：**
- 原片中出现的**每一种产品形态各一张干净图**：裸品、外包装、内包装、剖面、使用中状态……逐镜核对，**漏一种形态 = 生成时模型自由发挥编产品**（社区大量实测翻车点）。官方电商图最佳，不要用视频截图。
- 品牌资产：Logo、精确包装文字、价格与合规声明（这些同时列入"后期贴片"项，不依赖模型生成）。

**B. 可由插件自动生成（image 命令，登记进 manifest）：**
- **人物锚定图：一律文生图生成新身份，绝不从原片抽帧。** 复刻他人视频时，原片人物是真实肖像，拿它做生成素材涉及肖像权。生成一张同气质、同年龄感、同造型风格的新人物成本极低，没有理由省这一步。
- 场景/风格参考帧：还原原片的空间、光线、色调基准。

**生图模型选型（默认 4k，按需切换）：**
- 默认 / 出高清主图 / 海报级锚定图：`gpt-image-2-4k`（16:9 出真 4K UHD）——**不写 `--model` 就是它**；不可用/失败自动切 flash 快版。
- **画面内容或参考还原不满意、或要同一角色/产品出多张一致的图**：`--model gemini`（`gemini-3.1-flash-image`，flash 快版）+ `--ref <首图>` —— 先出 1 张新身份锚定图，再用它当 `--ref` 生成其余角度/场景，人物脸与产品形态保持一致（参考图一致性 flash 快版为佳）。这解决复刻里"锚定图跨镜漂"的老问题。

  ```powershell
  # ① 先生成新身份主锚定图（默认 gpt-image-2-4k）
  node studio.mjs image --prompt "<新人物设定>" --out assets
  # ② 用主图当垫图，出其它角度/场景，锁住同一张脸（切 flash 快版）
  node studio.mjs image --prompt "<同一人物，换到厨房侧身中景>" --model gemini --ref "assets/keyframe_xxx.png" --out assets
  ```

> **批量并发**：多张锚定图 / 多套方案不用逐张来——重复 `--prompt` 或加 `--n` 一次提交，插件用并发池并行跑（`--concurrency` 默认 3、上限 10），每张独立走兜底链、单张失败不炸整批，比串行快数倍。

产出 `assets/manifest.json`（每张图唯一职责）+ 给用户的人话清单（"请提供：①礼盒正面图 ②内包装图 ③产品剖面图"）。

## 第四步：文案与声音

- 口播逐句转写并按时间对齐；听不清的词标"不确定"待用户确认，禁止编造。
- **BGM 不提取原曲**（版权）。改为输出音乐风格描述（节奏、情绪、配器）供生成或让用户提供有授权的音乐。
- 音效只保留有帧证据的，标注所属分镜。

## 第五步：逐段绑定提示词

为每段写 `prompts/segNN.txt`：`@图片N` 引用与 manifest 顺序严格对应、每张图职责唯一且写进提示词（"产品外观以 @图片1 为唯一基准"）、段首尾状态承接、全局锁定层各段逐字一致。

## 第六步：交付与生成

工程包结构：

```text
<project>/
├── brief.md            # 原片信息 + 复刻目标（忠实复刻 / 换产品迁移）
├── shotlist.json       # 结构化分镜（含证据等级）
├── assets/manifest.json  + 已生成的锚定图
├── ASSETS-NEEDED.md    # 用户待补素材清单（人话）
└── prompts/segNN.txt   # 逐段绑定提示词
```

交付时明确告诉用户：补齐 `ASSETS-NEEDED.md` 里的素材后说一声，即可进入 pipeline.md 阶段 3 自动生成全片。

## 合规红线

- 复刻他人视频：人物必须新身份；不将原片画面或音频直接作为生成素材。
- "产品锚图可用原素材"的前提是**用户自有素材、自有产品**；此前提对"复刻别人的片子"不成立。
- 未经证实的卖点数据（容量、折扣、功效）保留为【待补】并提醒用户核实，不写进提示词。
