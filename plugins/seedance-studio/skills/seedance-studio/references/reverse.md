# 视频反推提示词（证据优先）

把一条参考视频拆解为可直接提交 Seedance 2.5 的提示词。方法论要点：**只写有帧证据的内容**，禁止把合理想象写成事实。

## 第一步：读取元数据

```powershell
ffprobe -v error -show_entries format=duration:stream=width,height,r_frame_rate,codec_type -of default=noprint_wrappers=1 "<视频>"
```

记录总时长、分辨率（推断比例）、是否有音轨。

## 第二步：抽帧观察（核心）

```powershell
# 1. 全片联系表：每秒 1 帧拼成网格，先建立整体印象
ffmpeg -y -i "<视频>" -vf "fps=1,scale=480:-1,tile=6x5" -frames:v 1 frames/sheet_%02d.png

# 2. 切镜候选点：场景变化检测（阈值 0.15，偏低以免漏掉同机位跳剪）
ffmpeg -i "<视频>" -vf "select='gt(scene,0.15)',showinfo" -f null - 2>&1 | findstr pts_time

# 3. 对快速动作/模糊转场段落做密集帧（每秒 8 帧）
ffmpeg -y -ss <起点秒> -t <时长> -i "<视频>" -vf "fps=8,scale=640:-1" frames/dense_%03d.png
```

然后**逐张查看**（用 Read 工具看图）。每个短动作必须记录：起始状态 → 移动方向 → 接触/结束状态 → 可见结果。单张静帧无法区分"拿起"还是"放下"——必须看连续帧。

## 第三步：音频（如有）

```powershell
ffmpeg -y -i "<视频>" -vn -acodec libmp3lame audio.mp3
```

口播内容让用户确认或提供文案；无法确认的台词标记为"不确定"，不得编造。**画面出现某动作不代表存在对应音效**——只写确认存在的声音。

## 证据分级铁律

- 每条观察分为 `已确认`（帧证据）/ `推断`（合理但无直接证据，需标注）/ `未知`（不写入提示词）。
- 开头钩子完整盘点：前景动作、背景动作、运镜、画面文字、音乐节奏——前 3 秒的所有元素都要覆盖，不得只保留主体动作。
- 画面文字：记录准确内容、语言、颜色、位置、出现与持续时间、是固定还是随物体运动。已确认的直接写入提示词；辨认不清的标"不确定"。
- 同一卖点下的多个快速硬切合并为一个分镜，但在镜头描写中保留内部切换顺序。
- 用户纠正后：清空旧判断，重看原始帧，不得只给旧结论换说法。

## 第四步：输出格式

先列出参考图上传顺序与各自职责（若用户提供了自己的产品/人物图），再输出一份可直接复制的提示词：

```text
【全局设定】视频参数、画面风格、核心运镜、整体声音分布（紧凑，只写生成所需）
【主体一致性】只锁定反复出现的核心人物/产品
【场景一致性】只锁定反复出现的核心场景
【文字】已确认的画面文字及其样式、位置、时间
【负面约束】只保留高风险项（主体漂移、文字乱码、钩子缺失）

0–3秒：镜头描写 / 画面与动作 / 声音
3–8秒：……
```

分镜时间用整数。交付前逐项核对：钩子每个成分已写入、动作方向与帧一致、每个音效有证据、每张参考图只有一个职责。

## 第五步（可选）：直接复刻

用户确认提示词后，回到 SKILL.md 出片流程提交生成。用户有自己的产品图时用 `--image` 绑定，并在提示词中声明"产品外观以 @图片1 为唯一基准"。原片总长超过 30 秒时按叙事段落拆分多次生成，最后 ffmpeg concat 拼接。
